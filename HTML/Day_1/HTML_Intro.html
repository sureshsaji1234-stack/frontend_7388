HTML → Hyper Text Markup Language It is a markup language. It is a ML to structure your information and layout to make a web page. HTML will structure your unstructured data. It is not a programming language; it's a markup language. Markup: No use memory and doesn't store. Hyper → One-to-one connected between two things. Text → Content or written info on the webpage. HTML not only structures text, it also structures the audio, video, images. MARKUP means using special tags to describe the structure and meaning of content. Language is a system with rules and syntax, used for communication between humans and systems. Predefined called tags in markup.
